## 📌 Про проєкт

У сучасному діловому та особистому спілкуванні люди постійно стикаються з психологічним тиском, провокаціями, знеціненням та маніпуляціями. Мета цього проєкту — надати кожній людині надійну **«систему раннього виявлення»** та інструменти психологічного самозахисту.

Проєкт складається з:

1. **Інтерактивної веб-сторінки** з сучасним преміальним дизайном для зручного пошуку, тренування та аналізу маніпуляцій.
2. **Повного текстового каталогу** [`tricks_100.md`](./tricks_100.md) у форматі Markdown для автономного вивчення.

## ⚡ Ключові можливості веб-додатку

- 🔍 **Живий миттєвий пошук:** пошук за назвою, психологічним механізмом, життєвими фразами чи ключовими тегами.
- 🏷️ **10 тематичних категорій:**
  1. *Невербаліка і мова тіла гри за владу* (піраміди з пальців, погляди, пози, вторгнення в простір);
  2. *Маніпуляції страхом та тривогою* (загрози звільнення, штучний поспіх, тактика катастрофи);
  3. *Маніпуляція провиною та обов'язком* (закон послідовності, нав'язаний борг, синдром мученика);
  4. *Атаки на професійну компетентність* (блеф, паралельні війни, мікро-чіпляння, отруйна похвала);
  5. *Статусний тиск і неповага* (примусове очікування, ігнорування в телефоні, низькі стільці);
  6. *Випробування нервів та емоційні пастки* (добрий і злий поліцейський, емоційні гойдалки, закон контрасту);
  7. *Трюки псевдо-успіху та ілюзорної вигоди* (міражі великих контрактів, лестощі як анестезія);
  8. *Маніпуляції увагою, часом та інформацією* (альтернативні питання, інформаційний потоп, висмикування з контексту);
  9. *«Чорне красномовство» та мовні софізми* (судження про правду, навішування ярликів, підміна тези);
  10. *Трансакційні ігри та китайські стратагеми* (пастки его-станів Батька/Дитини, маскування, поцілунок Юди тощо).
- 🚨 **4 рівні небезпеки:** колірне кодування від `Легкого` до `Критичного`.
- ⭐ **Вибране (Favorites):** збереження найактуальніших трюків у пам'яті браузера (`localStorage`).
- 🎯 **Тренажер дня (Randomizer):** інтерактивне тренування з показом життєвої провокації та прихованою відповіддю для відпрацювання захисних рефлексів.
- 📋 **Копіювання захисту:** швидке копіювання формулювань контрудару в буфер обміну в один клік.
- 🎨 **Преміальний дизайн:** темна палітра з неоновими акцентами, скляними ефектами (*glassmorphism*) та повною мобільною адаптивністю.

## 🌐 Публікація та запуск на домені tricks.lexis.blog

Проєкт налаштовано для автоматичного безперервного розгортання (**CI/CD**) через **GitHub Actions** на кастомний домен:

🔗 **[https://tricks.lexis.blog](https://tricks.lexis.blog)**

### Як влаштовано деплой

1. **GitHub Actions Workflow:** файл [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) автоматично публікує проєкт на GitHub Pages при кожному оновленні гілки `main`.
2. **Файл CNAME:** у корені репозиторію файл [`CNAME`](./CNAME) задає доменне ім'я `tricks.lexis.blog`.
3. **Налаштування DNS у вашого провайдера домену (`lexis.blog`):**
   - **Тип запису:** `CNAME`
   - **Хост / Піддомен (Host / Name):** `tricks`
   - **Значення (Value / Target):** `yarovision.github.io.`
   - **TTL:** `300` або `Auto`
4. **У налаштуваннях репозиторію GitHub:**
   - Перейдіть у **Settings** -> **Pages**;
   - У розділі **Build and deployment** -> **Source** оберіть: **GitHub Actions**;
   - Переконайтеся, що стоїть галочка **Enforce HTTPS**.

## 🚀 Як запустити локально

Веб-додаток не вимагає встановлення зовнішніх залежностей або збирачів.

### Варіант 1: Запуск через простий HTTP-сервер Python

```bash
# У корені проєкту виконайте:
python3 -m http.server 8080
```

Після цього відкрийте у браузері: [http://localhost:8080](http://localhost:8080)

### Варіант 2: Пряме відкриття у браузері

Просто двічі клацніть на файл `index.html` або перетягніть його у будь-який сучасний браузер (Chrome, Safari, Firefox, Edge).
